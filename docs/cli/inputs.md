---
title: inputs
description: Migrate previous assumptions and decision files into a unified inputs file.
---

`inputs migrate` converts earlier assumptions and decision review inputs into the typed input format used by StackToIT.

## Syntax

```sh
stacktoit inputs migrate --profile NAME --out FILE [options]
```

## Example

```sh
stacktoit inputs migrate \
  --profile default \
  --out ./inputs.yaml \
  --assumptions ./assumptions.yaml \
  --decisions ./decisions.yaml \
  --register ./terraform-stacktoit/decisions.json
```

Optional fields include `--evidence-id`, `--answered-at` and `--report`. The migration produces a mapping report and refuses ambiguous conversions instead of silently guessing.

For a new assessment, use the `inputs-template.yaml` generated by `assess` as your starting point instead of first creating legacy files.
